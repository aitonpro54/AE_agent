Продукт хранит вход, профиль, выбор переносов и задания серии. Модули Core
работают с точными объектами AE и конечным набором свойств. Журнал и подтверждение
остаются у Core. Нативный путь идёт через `inspect → build → propose → dry-run →
run → fresh inspect`. Исходные квитанции сохраняются до следующего шага. UNKNOWN
устанавливается по оригинальному dispatch и журналу до дальнейших записей.
