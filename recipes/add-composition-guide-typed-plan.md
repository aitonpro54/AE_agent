# Add Composition Guide Typed Plan

## Goal

Добавить безопасный generated composition guide overlay в композицию через existing typed bridge tools.

## Applies When

- Пользователь просит добавить single composition guide, guide layer, 16:9 frame guide, center-safe guide, или visual guide overlay.
- Допустима visual overlay adaptation: generated shape layer inside the comp, not native AE guide records or a native non-rendering guide layer.
- Target comp is either newly generated by the plan with explicit comp settings, or an explicit comp target that is read back before the guide overlay is added.
- If the user needs exact `guideLayer=true`, ruler guides, snapping guides, locked/non-rendering guide-layer behavior, or `CompItem.addGuide` semantics, fail closed and request a separate typed-tool contract.
- Задача не требует raw script execution, deleting existing layers, changing existing artwork, render queue changes or template batch updates.

## Plan Pattern

1. Establish the target composition. Run `create_comp` only when the user requests a new generated comp; otherwise require an explicit target comp identity and read it with `get_comp_details`.
2. Use the target comp width and height to compute one requested overlay guide geometry. If the user does not specify exact geometry, use a centered 16:9 rectangle guide inside the comp bounds.
3. Run `create_shape_layer` for one generated guide overlay with a clear generated prefix, stable name, and non-destructive placement above existing artwork.
4. Include `verifyAfter:true` and a stable `idempotencyKeyTemplate` on the mutating shape-layer create step.
5. Run `get_comp_details` with layer read-back for the same comp.
6. Run `get_layer_details` for the generated guide overlay layer to confirm the requested 16:9 frame or guide-line geometry.

## Safety Gates

- Mutating composition workflow.
- Requires validated Agent plan, dry-run, explicit confirmation, `allowMutations:true`, idempotency and post-mutation read-back.
- Use checkpoint or edit-session protection for confirmed live runs.
- Use generated-prefix layer names and never delete, rename, relink or reorder existing user layers as part of this recipe.
- Do not promise native AE guide records, `guideLayer=true`, ruler snapping, locked/non-rendering guide-layer behavior, or `CompItem.addGuide`; fail closed when exact native guide mutation is required.
- Do not use this recipe for existing layer cleanup, masks, expressions, source relinking, template batch changes, render queue changes or raw ExtendScript.

## Verification

- The plan creates or targets exactly one comp and adds one generated composition guide overlay shape layer.
- `get_comp_details` read-back shows the generated guide overlay layer in the target comp with the expected generated name and no unexpected changes to user layers.
- `get_layer_details` read-back shows the requested 16:9 frame or guide-line geometry for the generated overlay layer.
- The plan contains only optional comp creation, generated shape-layer guide overlay creation and typed read-back steps.
- Native `guideLayer=true`, ruler guide, snapping, locked/non-rendering guide-layer and `CompItem.addGuide` behavior is not claimed; exact native composition guide requests are reported as a typed-tool gap.
