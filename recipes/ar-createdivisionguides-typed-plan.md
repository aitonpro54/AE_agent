# AR Create Division Guides Typed Plan

## Goal

Add generated visual division guide overlays to one explicit composition by
computing reviewed vertical and/or horizontal divisions from typed comp
dimensions, then reading the generated guide layers back.

## Applies When

- The user asks to create division guides, grid division guides, thirds,
  columns, rows, or references `AR_CreateDivisionGuides.jsx`.
- A generated shape-layer overlay adaptation is acceptable instead of native AE
  ruler guide records.
- The target comp is newly generated by the plan or is an explicit existing comp
  read back with `get_comp_details` before guide geometry is computed.
- The division request is represented as a reviewed `divisionGuideSpec` with
  explicit `columns` and/or `rows` values greater than one, optional margins,
  and optional guide style.
- Source-exact ScriptUI prompts, native `CompItem.addGuide` behavior, ruler
  snapping, guide-index semantics, existing guide cleanup, or raw script
  execution are not required.

## Plan Pattern

1. Establish exactly one target composition. Run `create_comp` only when the user
   requests a new generated comp; otherwise require an explicit comp target and
   read it with `get_comp_details`.
2. Use typed comp width and height from `create_comp` or `get_comp_details` to
   compute the reviewed division geometry. For `columns:n`, create `n - 1`
   vertical internal division lines; for `rows:n`, create `n - 1` horizontal
   internal division lines.
3. Fail closed when target comp dimensions are unavailable, the comp inventory is
   ambiguous, division counts are missing or less than two, computed guide
   coordinates fall outside the comp bounds, or native AE guide records are
   required.
4. Run `create_shape_layer` for generated division guide overlay layers with a
   clear generated prefix, stable names, and non-destructive placement above
   existing artwork.
5. Use `add_effect` with `ADBE Fill` only when the reviewed guide style requires
   explicit color styling.
6. Include idempotency keys and expected generated layer names on mutating steps.
7. Run `get_comp_details includeLayers:true` and `get_layer_details` after
   mutation to confirm the generated guide layer count, names, and geometry.

## Safety Gates

- Mutating composition workflow.
- Requires validated Agent plan, dry-run, explicit confirmation,
  `allowMutations:true`, idempotency, checkpoint or edit-session protection, and
  post-mutation read-back before adding guide overlays.
- Create only generated shape-layer guide overlays in the target comp; preserve
  existing user layers, sources, masks, expressions, effects, keyframes,
  selection state, layer order, project items, render queue items, files, and
  non-target comps.
- Do not delete, rename, reorder, relink, or restyle existing layers as part of
  this recipe.
- Do not claim native AE guide objects, ruler snapping, `CompItem.addGuide`,
  `removeGuide`, guide-index semantics, source-exact prompt UI behavior, or raw
  ExtendScript execution.

## Verification

- Pre-run evidence identifies the target comp, width, height, current layer
  count, reviewed `divisionGuideSpec`, computed line count, and generated layer
  names before confirmation.
- The dry-run plan lists the computed vertical and/or horizontal guide
  coordinates and confirms they are inside comp bounds.
- `create_shape_layer` creates only the expected generated division guide
  overlays, with optional `ADBE Fill` applied only to generated guide layers.
- Post-run `get_comp_details includeLayers:true` and `get_layer_details` show the
  expected generated guide overlay count, generated names, and geometry in the
  target comp.
- Unsupported native guide records, ruler snapping, source-exact ScriptUI
  prompts, existing guide deletion, guide-index mutation, broad project scans,
  raw script execution, and exact source JSX behavior are reported as typed-tool
  gaps.
