# Add Assorted Composition Guides Typed Plan

## Goal

Добавить безопасные generated shape-layer guide overlays в композицию через existing typed bridge tools.

## Applies When

- Пользователь просит добавить assorted composition guides, edge/center guide lines, action safe or title safe visual guides.
- Допустима visual overlay adaptation: generated shape layers inside the comp, not native AE guide records.
- Target comp is either newly generated by the plan with explicit comp settings, or an explicit comp target that is read back before guide layers are added.
- If the user needs real native AE composition guides, ruler guides, or `CompItem.addGuide` semantics, fail closed and request a separate typed-tool contract.
- Задача не требует raw script execution, deleting existing layers, changing existing artwork, render queue changes or template batch updates.

## Plan Pattern

1. Establish the target composition. Run `create_comp` only when the user requests a new generated comp; otherwise require an explicit target comp identity and read it with `get_comp_details`.
2. Use the target comp width and height to compute five overlay guide groups: edge frame, center vertical, center horizontal, action safe and title safe.
3. Run `create_shape_layer` for each generated guide overlay with a clear generated prefix, stable names and non-destructive placement above existing artwork.
4. Use `add_effect` with `ADBE Fill` on the guide overlay layer or layers that need a consistent guide color.
5. Include `verifyAfter:true` and a stable `idempotencyKeyTemplate` on each mutating create/effect step.
6. Run `get_comp_details` with layer read-back for the same comp.
7. Run `get_layer_details` for the guide/effect layer evidence needed to confirm shape-layer geometry and `ADBE Fill` presence.

## Safety Gates

- Mutating composition workflow.
- Requires validated Agent plan, dry-run, explicit confirmation, `allowMutations:true`, idempotency and post-mutation read-back.
- Use checkpoint or edit-session protection for confirmed live runs.
- Use generated-prefix layer names and never delete, rename or reorder user layers as part of this recipe.
- Do not promise native AE guide objects, ruler guides, snapping guides, or `CompItem.addGuide`; fail closed when exact native guide mutation is required.
- Do not use this recipe for existing layer cleanup, masks, expressions, source relinking, template batch changes, render queue changes or raw ExtendScript.

## Verification

- The plan creates or targets exactly one comp and adds the requested guide overlays as generated shape layers.
- `get_comp_details` read-back shows the expected five generated guide overlay layers in the target comp without unexpected changes to user layers.
- `get_layer_details` and effect read-back show the expected guide geometry and `ADBE Fill` on the intended generated guide layer or layers.
- The plan contains only optional comp creation, generated shape-layer guide creation, optional fill-effect styling and typed read-back steps.
- Native `CompItem.addGuide` behavior is not claimed; exact native composition guide requests are reported as a typed-tool gap.
