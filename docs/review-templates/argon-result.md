## Формат ответа и ручная точка

Верни review/stage IDs, base/target SHA и request SHA-256 из manifest; состав фактически прочитанного, пропуски/обрезку; verdict go/revise/stop/insufficient-evidence. На каждый finding: ID, P0–P3, утверждение, сценарий, commit:path:line/test, уверенность, минимальная проверка. Гипотезы и недостающее live evidence выдели явно. Codex присвоит каждому пункту статус «подтверждён / уже учтён / не подтверждается / требует проверки», приоритет, evidence и новизну. Исправления только отдельной согласованной задачей.

Codex показывает пользователю полный запрос и manifest: «Пакет готов к ревью, не отправлен». Отправлять через существующий ARGON_BrowserUse только после явного разрешения на данный payload. Внешний verdict не является разрешением исполнить изменения. Повторный обмен автоматически не запускать.
