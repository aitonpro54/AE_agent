# Roadmap 1.1 release notes - 2026-05-14

Этот блок довел AE Agent 1.0.0 до более практичного Agent workflow: меньше догадок перед планированием, яснее review/run UX, надежнее provider failures и проще проверять установленную CEP-панель.

## Что изменилось

- Добавлены compact workflow presets в CEP composer: timing выбранных слоев, precompose/rename, text/shape layout, basic animation и source replacement.
- Plan Review transcript теперь явно показывает affected targets, mutation count, checkpoint expectation, warnings и read-only/protected run readiness.
- Agent planning получает компактный Project Context Snapshot: bridge context, active comp, selected layer/source hints, render queue count и recent events. Snapshot остается подсказкой, а не разрешением на мутацию.
- Run results яснее показывают checkpoint/edit-session состояние, а failed mutating runs получают текстовый `recoveryHint` без automatic restore действий.
- Provider failures нормализованы через стабильный `providerError`: `missing_auth`, `missing_model`, `model_unavailable`, `network_failure`, `rate_limited`, `malformed_response`, `provider_error`.
- Добавлен `scripts\cep-sync-health.js` для repo-versus-installed CEP health и safe sync tracked files.
- `scripts\install-cep-panel.ps1 -SyncOnly` использует тот же safe sync helper.

## Не входило в блок

- Отдельная русификация UI/документации.
- Render workflow polish. Существующие render queue setup tools остаются доступными, но запуск render и отдельная render-веха не добавлялись.
- Automatic restore UI или restore-кнопки после failed runs.
