# Рабочие продукты над AE Core

Здесь размещаются самостоятельные workflow-пакеты: задания, инструкции, compiler и проверки пользовательского результата. Они используют публичные контракты AE Core. Соединение, разрешения и исполнение принадлежат существующему MCP-контроллеру.

Первый пакет — [Titles](titles/README.md). План разработки и порядок следующих этапов — [внешние продукты](../plans/external-products-titles-20261029.md).

Production-код продукта не импортирует `core4/`, legacy runtime или соседние private реализации. Test-only fixtures могут проверять совместимость с настоящим Broker в отдельном temp. Продукт не читает installed credentials/state, не поставляет public grants и не создаёт второй runtime. Изменение продукта проверяется его собственными тестами; изменение AE capability — её адресными проверками.
