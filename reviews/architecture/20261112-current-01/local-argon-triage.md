## Что принять из рекомендаций и следующий разумный блок

1. **Сохранить базовый каркас.** Оба review и локальная сверка поддерживают typed solution library, внешние product compilers, server authority, ownership/checkpoints и UNKNOWN/no-replay. Ни current read, ни audit не расширяют права на user-owned AEP/templates/assets.
2. **Упростить границу metadata assembly ограниченно.** Pure composition/registry helpers — наиболее обратимая архитектурная правка; она должна сохранить fixed trusted registration, actual transitive closure и package verification. Наличие файла в package и его активность — разные вопросы.
3. **Отделить диагностический дефект от намеренного fence.** У G-01 реально теряется точный error code, но signed reset retirement уже существует. Предложение Argon безусловно снимать guard после sync throw конфликтует с существующим no-replay контрактом и требует более сильного доказательства pre-dispatch отказа.
4. **Исправлять проверяемые локальные гарантии.** Lower close promise, added builder keys и catalogRevision имеют точные source arguments. Полного runtime shutdown defect, package nondeterminism или текущей поломки Titles из них не следует.
5. **Proof границы оставить явными.** Исторические tests/native evidence и exact reuse не превращаются в current full release. Уже выполненная local-pro сверка не повторяется; ограниченный нынешний empty-read proof не закрывает automatic startup/new-identity products.

Разумный следующий **engineering** блок после отдельного назначения — только registry bootstrap diagnostics/provenance (G-01): сохранить исходную ошибку и определить безопасный terminal outcome для достоверно вернувшегося callback, сохранив no-replay/retirement при неизвестной доставке. Его критерии — VM/native-fake fixtures, unchanged signed-reset safety и отсутствие автоматической очистки UNKNOWN; live AE не нужен для начального source исправления. Pure helper extraction/G-02 — следующий независимый архитектурный кандидат, без объединения всех замечаний в большую миграцию. В текущем аудите этот engineering block не начат.
