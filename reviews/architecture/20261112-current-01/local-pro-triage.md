## Архитектурное решение и оставшиеся пробелы

Базовую архитектуру сохранить. Главный приоритет — точность границы принятого normal path и восстановительных переходов текущего production-профиля; существенная часть нужных механизмов и tests уже существует. Главная новая локальная ошибка — семантика повторного нижнего close, с проверенным верхним guard в обычном Owner. AE-06 не подтверждает текущий дефект Titles; AE-07 — ограничение общей гарантии для будущего/изменённого builder, не найденная мутация вне approval.

Из альтернатив упрощения наиболее обратимо выделение pure composition/registry helpers: оно не требует мигрировать историю и authority. Переписывание Broker/recovery, объединение lifecycle identities, database migration и расширяемые пользовательским кодом privileged plugins имеют значительно больший миграционный риск без доказанной необходимости. Перенос host-specific proof в модуль не должен переносить выдачу authority продукту. External Titles/Slideshow продолжают владеть заданиями/compiler/templates; Core и admitted operation packages — typed исполнением и server gates.

Не хватает: полного списка обязательных сценариев выбранного broad composition; применимых актуальных records для точно затронутых интеграционных seams; current startup proof для предусмотренных launch contexts; текущей native mutation/product acceptance на новой identity, если её будут заявлять; доказанного caller-контракта concurrent/rejected lower close; измеренных history/startup budgets. Полный security/release audit и исчерпывающий поиск всех логов не выполнялись.
