## Ответ по первому программному пакету

[Оригинал ответа](response.txt), [receipt без адреса аккаунта](receipt.json),
[ограничения покрытия](coverage.txt).
Оба приложения фактически загружены; исходный ответ совпал по SHA после повторного
открытия [беседы](https://gemini.google.com/app/3df76960cae8bec8).
UI показывал «Задача / 4 Argon» без отдельного выбора effort.

Argon изменил первоначальную текстовую рекомендацию: отказался от назначения
внешнего Kumo простым backend для мутаций в том же процессе AE. Причины по коду —
consume-on-read и удаление ответов, отсутствие совместимого сохраняемого журнала
и привязанных исходных квитанций. Это препятствие для штатного Kumo 0.3.2 в данном
scope; не доказательство невозможности специально переработанного backend.

Предпочтение — исправление P0 в Core и ограниченный нативный модуль
duplicate/replace с возможным переносом MIT-примитивов. Размещение реализации
в Core само по себе не даёт корректного восстановления partial/late outcome.

Независимый ae_architect (Sol 6.1 XHigh) проверил пять спорных предложений ответа.
Отправлено отдельное дополнение: порядок durable intent/dispatch; historical-only
native-read-disposition; TOCTOU при удалении checkBytes; потеря полных имён в
inventory; пределы observer Kumo и недоказанная оценка объёма нативного модуля.
Ответ на дополнение получен и независимо разобран тем же ae_architect.

## Окончательный разбор дополнения

[Оригинал](supplement/response.txt), [версия после повторного открытия](supplement/response-reopened.txt),
[receipt](supplement/receipt.json), [покрытие и недостающие зависимости](supplement/coverage.txt).
Оба приложения доставлены. Raw SHA двух извлечений ответа различаются: после
reopen изменились переносы в code blocks и исчез конечный UI-статус «Готово».
Локально подтверждено равенство остального текста после этой нормализации;
обе исходные версии сохранены. Побайтное равенство не заявляется.

| Предложение | Решение после проверки исходников |
|---|---|
| Отказ от штатного внешнего Kumo backend в том же AE | Принято для ближайшего scope. Переработанный backend теоретически возможен, но его стоимость не доказана |
| Перенести begin к poll; закрывать неизвестное чтение историческим disposition | Отозвано Argon. Сохранять write-ahead; native-read-disposition — фиксированный исторический валидатор |
| Разделить caller timeout и время физического завершения inspect | Условно принято как направление, не готовый patch. Только закреплённый direct project-inspection effect:none, ограниченное окно drain, без новых команд, со строгой привязкой late complete и отдельным статусом ожидания |
| nativeGuard/heartbeat доказывают живое исполнение | Отклонено. Guard выставляется до evalScript и локален; poll может молчать во время нормального callback. UNKNOWN не снимается по этим признакам |
| start-over автоматически disconnect и погашает старую команду | Уточнено независимым review: fenceForStartOver закрывает выдачу, но допускает старый callback в старый журнал; сам disconnect не вызывает |
| Снять JSX checkBytes, заменить inventory полями name.length/FNV | Отозвано Argon. Сохранить точную проверку bytes после confirm и все ранее защищаемые поля |
| Поднять лимиты до 256 МиБ / 2048 items / 512 КиБ кадра | Только кандидаты для измерения. Требуется сквозной бюджет UTF-8 bytes, escaping, повторяющихся snapshot/revision/receipts и согласование всех transport/schema/recovery ограничений |
| Отсутствие heartbeat/lock гарантирует эксклюзивность | Отозвано Argon. Observer даёт диагностическое наблюдение, не универсальную блокировку чужого writer; установленный Kumo не удалять |
| Синхронный evalScript — доказанная атомарная транзакция AE | Отклонено как гарантия. Post-confirm recapture сужает окно; отсутствие reentrancy/других actors/partial effects этим не доказано |
| Нативный модуль автоматически получает recovery; достаточно 120–150 строк | Отозвано Argon. Нужны contract/admission/result profile/proof/started и проверки partial/late outcome |
| forbid-active и allow-with-frame-verify закрывают expressions | Первый допустим только с честно ограниченным fail-closed scope всех затрагиваемых ссылок. Второй не принят как профиль сохранности пользовательского AEP: PNG proof не проверяет семантику сцены, один кадр не покрывает другие времена и comps |

Независимая проверка уточнила: текущий owner сворачивает timeout при pending в
owner_outcome_uncertain. Поэтому изменение ожидания затрагивает классификацию
статуса и освобождение физической очереди, а не только один таймер. Durable complete
может завершить команду, но не должен повторно исполнять её или «возрождать» уже
завершившийся вызов MCP. При неоднозначности сохраняется UNKNOWN.

**Итог:** сначала адресные P0 готовности/диагностики/точного поиска и проверяемого
recovery, затем один нативный duplicate/replace-контракт Core с сохранением исходных
слоёв и проверкой результата. Large-project/save расширять отдельными блоками без
ослабления инвариантов. Перенос подходящих MIT-примитивов допускается; отдельный
Kumo MCP не является обязательной зависимостью. Независимая параллельная работа
возможна на раздельных AE-процессах, копиях AEP и output paths; импорт результата
требует отдельной проверки. Два writer в одном AE общей гарантии не дают.

Это завершённый консультационный этап. Исправления, тесты продукта, установка,
конфигурация, перезапуск AE, сохранение AEP и рендер в нём не выполнялись.

Проверки артефактов: SHA исходников/приложений/ответов, JSON, синтаксис упаковочных
scripts и локальные ссылки — PASS. Diff check текстов и scripts — PASS, кроме
девяти исходных trailing spaces в `supplement/response-reopened.txt`; они сохранены
намеренно ради точных исходных bytes и SHA, документ не нормализован.

## Границы доказательств

Передача файлов и сохранность ответов проверяются контроллером браузера. Заявление
Argon о прочтении всех файлов — его self-report, а не независимое доказательство
полного покрытия. Статическое ревью не доказывает работоспособность предлагаемых
изменений, отсутствие всех дефектов или пригодность к live-установке.
