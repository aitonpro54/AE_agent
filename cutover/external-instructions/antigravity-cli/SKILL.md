# Вызов Antigravity

В legacy AE Agent (`C:/Users/Ant/Documents/Codex/AE_agent`) пользователь разрешил
постоянный маршрут: scoped реализацию, отладку и содержательную техническую
валидацию выполняет Sol 6.1 High; XHigh — сложные взаимодействия компонентов,
safety/security/authority и устойчивые дефекты. Flash configured High применяется
только к ограниченным правкам с ясной приёмкой в категориях с подтверждённой пользой.
Для исполнения такой подходящей AE правки применяй skill без
повторного разрешения на вызов Flash; выбор задачи и эскалацию определяют
проектный `AGENTS.md` и `docs/model-routing.md`. Сама настройка маршрута не требует
демонстрационного запуска. В VideoScout все задачи Antigravity выполняет
Flash 3.8 High согласно проектным правилам, включая спорные визуальные решения.
В прочих проектах нужны прямое
поручение через Antigravity либо явный вызов skill. Само упоминание модели этого не заменяет.
Выбранная модель Codex ведёт текущий чат; её автоматически не переключать.

В Core `.gemini/config/mcp_config.json` уже регистрирует MCP server `after-effects` со старым source path; он может быть адресно переключён на подготовленные Core paths только в отдельно разрешённом cutover. Это отдельно от `agy-bridge` executor profile: `ae-agent` задан только в legacy `AE_agent/config/agy-bridge.json` и не provisioned для Core. Не переиспользуй source-bound profile молча и не создавай скрытый fallback. Для Flash call должны быть доступны действующий executor contract и применимое разрешение.

Любую авторизацию Antigravity (OAuth/login/повторный вход) во всех проектах открывай в Google Chrome в выделенном профиле пользователя Elowen Carter. Перед выбором аккаунта и подтверждением OAuth проверь, что это именно Elowen Carter, а не другая сохранённая учётная запись. Если профиль или личность аккаунта не найдены либо неясны, останови вход и уточни у пользователя; не подменяй их другим профилем или аккаунтом. Не выдумывай имя каталога профиля или email и не меняй глобальный браузер по умолчанию.

- Для обычного проекта Codex прочитай [references/codex.md](references/codex.md). Flash — один исполнитель; дополнительные модели и специалисты не вызываются.
- Для задачи в legacy `AE_agent` прочитай [references/ae-agent.md](references/ae-agent.md); профиль `ae-agent`, результат проверяет выбранная модель чата. Core AGY profile не provisioned.
- Для поручения в VideoScout или разового прямого вызова agy прочитай [references/videoscout.md](references/videoscout.md).

Соблюдай границы текущего пользовательского запроса, разрешения и правила проекта. Мост не меняет права сохранённого проекта agy. После ошибки сначала читай status и фактические файлы; не запускай повтор автоматически.
